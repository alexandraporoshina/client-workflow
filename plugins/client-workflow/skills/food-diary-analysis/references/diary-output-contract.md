1. Что прямо записано.
2. Хронология еды, сна, нагрузки и заметок — только где есть данные.
3. КБЖУ: известное, оценка с допущениями, неизвестное.
4. Наблюдения специалиста.
5. Альтернативные объяснения, пробелы и вопросы к сессии.

# Внутренний разбор КБЖУ

Внутренний разбор предназначен только специалисту. Если есть только
фотография, допустим широкий диапазон КБЖУ с пометкой `низкая точность`,
видимыми компонентами и всеми допущениями. Не создавай точечный расчёт по
изображению и не рассчитывай ничего, если состав или порция слишком неясны.

# Нейтральный PDF для совместного просмотра

- Время.
- Еда.
- Заметка клиента.
- Необязательный коллаж явно выбранных фотографий дневника с указанным временем.

Клиентский PDF — материал для совместного просмотра. Он не является клиническим заключением или нутриционным назначением.

Рендерер принимает только этот JSON-контракт:

```text
title: string
period: string
entries:
  - time: HH:MM
    food: string
    client_note: string
photos: # необязательное поле
  - path: string # путь к существующему файлу изображения
    time: HH:MM | "время не указано"
```

Неизвестные поля на любом уровне отклоняются до создания PDF.

Фотографии попадают в PDF только из поля `photos`; содержимое снимков не
анализируется и не описывается. Для каждого элемента обязательны `path` и
`time`. Если файл по `path` отсутствует, PDF не создаётся.

# Запрещённые для PDF категории

- Гипотеза.
- Диагноз.
- Профессиональная оценка.
- Риск.
- Супервизионный вопрос.
- КБЖУ, диапазон КБЖУ и допущения расчёта.
