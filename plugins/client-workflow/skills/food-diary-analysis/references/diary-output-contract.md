# Нейтральный PDF для совместного просмотра

- Время.
- Еда.
- Заметка клиента.
- КБЖУ только с отмеченной точностью.

Клиентский PDF — материал для совместного просмотра. Он не является клиническим заключением или нутриционным назначением.

Рендерер принимает только этот JSON-контракт:

```text
title: string
period: string
entries:
  - time: HH:MM
    food: string
    client_note: string
    nutrition:
      status: insufficient_data
```

Для оценки КБЖУ допустим только такой блок:

```text
nutrition:
  status: estimated
  kcal: number
  protein_g: number
  fat_g: number
  carbs_g: number
  assumptions: string
```

Неизвестные поля на любом уровне отклоняются до создания PDF.
