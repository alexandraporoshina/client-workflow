# Client workflow for Codex

Приватный набор для специалиста по питанию:

- `client-session-workflow` — разбор подтверждённых транскрибаций, подготовка к сессии и локальная динамика;
- `food-diary-analysis` — разбор выбранного дневника питания и нейтральный PDF для совместного обсуждения с клиентом.

В репозитории нет клиентских данных. Навыки не отправляют материалы во внешние системы и не меняют Google Drive без отдельного явного подтверждения.

## Установка коллегой

```bash
git clone <адрес этого приватного репозитория>
cd client-workflow
codex plugin marketplace add .
codex plugin add client-workflow@personal
```

После установки нужно начать новый task Codex. Клинические решения и клиентские сообщения остаются за специалистом.
